## Convención de versionado

- Cada relevamiento nuevo se guarda como un archivo inmutable.
- Formato recomendado:
  - `relevamiento-ui-ux-v{N}-YYYY-MM-DD.md`
  - `plan-maestro-ui-ux-v{N}-YYYY-MM-DD.md`
  - `seguimiento-plan-maestro-v{N}-YYYY-MM-DD.md`
- No se sobreescriben versiones anteriores.
- Si cambia el criterio, se crea una nueva versión y se referencia la anterior.
